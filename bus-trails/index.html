경로 상세

    경로는 이렇게 비교해요.

    최소 소요 시간·환승 적게·도보 최적화 등 서로 다른 조건으로 TfL에 조회합니다. Google을 연결하면 Google의 버스 선호 경로도 비교해요. 각 구간을 다시 검사해 버스와 도보만 남기고, 출발 시점부터 기다리는 시간을 포함해 도착 순서로 정렬합니다.

    조회된 후보 중 가장 빠른 경로입니다. 모든 정류장 조합을 완전 탐색한 전역 최단 경로는 아니며, 도로 상황과 버스 운행에 따라 실제 시간은 달라질 수 있어요. 30분은 총 도보 시간이며, 예상 도보 속도는 보통으로 계산합니다.

    지도와 경로 연결

    TfL은 키 없이 먼저 조회합니다. Google 지도·추가 경로 비교는 본인의 Google Maps API 키가 필요해요.

    Maps JavaScript API와 Routes API를 활성화하고 결제를 연결해야 합니다. API 사용량에 따라 요금이 발생할 수 있어요. 웹사이트 제한을 https://swk99.github.io/*로 설정하세요. 검색 한 번에 Google 경로 요청 최대 2회가 발생합니다.

    키는 현재 탭의 세션 저장소에만 저장합니다. GitHub 저장소에는 올리지 않으며 각각 Google·TfL 요청에만 사용합니다. 키를 채팅으로 보내실 필요는 없어요.

    Google 연결 방법
    1. Google Cloud에서 프로젝트와 결제 계정을 연결합니다.
    2. Maps JavaScript API와 Routes API를 켭니다.
    3. 브라우저 API 키에 위 웹사이트 제한과 두 API 제한을 적용합니다.
    4. 사용량 한도·예산 알림을 설정한 뒤 여기 입력합니다.
    공식 설정 안내 ↗

    개인정보·이용 안내

    검색한 출발지·도착지·출발 시각은 TfL로 전송됩니다. Google 키를 연결하면 동일한 검색 정보가 Google Maps로도 전송됩니다. 현재 위치는 버튼을 누르고 권한을 허용했을 때만 사용합니다.

    검색 기록과 위치는 이 앱의 서버나 저장소에 보관하지 않습니다. 입력한 API 키만 현재 탭의 세션 저장소에 보관하며 설정에서 삭제할 수 있습니다.

    경로·시간은 참고용 예상치이며 실제 운행, 정류장 표지판과 보행 가능 여부를 확인하세요. Google의 도보·자전거 경로에는 인도나 보행로 정보가 빠질 수 있습니다.

    이 앱은 TfL 또는 Google의 공식 앱이 아닙니다. TfL 데이터 이용 안내 · Google 개인정보처리방침 · Google Maps 이용약관
