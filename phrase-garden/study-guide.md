# Seonwoo의 실전 영어 표현 1,000

구동사·다어동사·관용구·대화 표현 | 한글 뜻 + 영어 예문 | 영국 생활과 직장 회화 중심

**20개 주제 × 50개 = 1,000개 · 하루 20개 × 50일**

작성일: 2026-10-21

## 이 자료의 구성

- 0001–0500: 구동사와 관련 다어동사 중심. 전치사 동사, 관용적인 동사구도 함께 포함했다.
- 0501–1000: 직장·일상 관용구와 자연스러운 대화 표현.
- 아주 기본적인 동작 표현보다는 **단어만 보고 뜻을 짐작하기 어렵거나 실제 대화에서 쓰기 좋은 표현**에 무게를 두었다. 복습할 만한 익숙한 표현도 일부 포함했다.
- 각 항목은 **표현 → 예문에 해당하는 한글 뜻 → 직접 작성한 영어 예문** 순서다. 여러 뜻을 전부 나열한 사전이 아니라, 한 번에 한 가지 쓰임을 익히는 암기장이다.
- `[영국]`, `[미국]`은 대표적인 사용 경향이며 그 지역에서만 쓴다는 뜻은 아니다. `[구어]`는 주로 편한 대화, `[격식]`·`[문어]`는 더 격식 있는 말이나 글, `[기술]`·`[업무]`는 해당 맥락을 나타낸다. 표시가 없다고 모든 상황에서 격식체라는 뜻은 아니다.
- `your`, `someone`, `oneself` 등은 문장 속 사람에 맞게 바꾼다. 예: `pull oneself together` → `pull myself together`.
- 영국·미국 변형은 듣기 대비를 위해 일부 별도 수록했다. 예: `touch wood / knock on wood`, `a drop in the ocean / a drop in the bucket`.

## 외우는 방법

1. 먼저 영어 표현만 보고 뜻을 말한다. 처음부터 아는 표현은 체크하고 넘어간다.
2. 한글 뜻만 보고 영어 표현을 떠올린 뒤, 예문을 소리 내어 읽는다.
3. 그날 표현 중 3개는 **자기 상황에 맞는 문장**으로 바꾼다.
4. 다음 날, 3일 뒤, 7일 뒤에 다시 떠올려 본다. 잘 안 떠오르는 항목은 체크를 해제한다.
5. 20개가 벅차면 하루 10개로 나눠 100일 동안 진행해도 된다. 체크는 “봤음”보다 “뜻만 보고 말할 수 있음”의 표시로 쓰자.

## 구동사 어순: 먼저 알아둘 세 가지

- **분리 가능한 구동사**: `put the task off / put off the task`처럼 목적어 위치를 바꿀 수 있다. 대명사를 쓰면 `put it off`가 되고, `put off it`은 쓰지 않는다.
- **분리할 수 없는 구조**: `look into the issue`, `come up with an idea`처럼 뒤에 목적어를 놓는다. `come an idea up with`처럼 쪼개지 않는다.
- **목적어 없이 쓰는 경우**: `The problem cropped up.`처럼 쓴다. 같은 동사구라도 뜻에 따라 문형이 달라질 수 있으니 예문 전체를 함께 익힌다.

  **예문:** Could you chase up the missing invoice?

## 비슷해 보여도 구분해서 외우기

| 표현 | 구별할 점 |
| --- | --- |
| `follow up on` / `chase up` | 전자는 후속 확인, 후자는 지연된 답변·처리를 재촉하는 느낌이 더 강하다. |
| `put off` / `hold off on` | 전자는 미루기, 후자는 당장은 착수하지 않고 기다리기. |
| `bring up` / `come up` | 내가 화제를 꺼내면 bring up, 화제·문제가 나오면 come up. |
| `take over` / `take on` | 기존 업무·권한을 넘겨받는 것과 새로운 책임을 맡는 것의 차이. |
| `go ahead with` / `go through with` | 진행 결정과, 어려움·망설임에도 실제로 실행하는 것의 차이. |
| `talk over` / `talk into` / `talk out of` | 상의하기 / 하도록 설득하기 / 하지 않도록 설득하기. |
| `look into` / `look over` / `look through` | 조사하기 / 빠르게 검토하기 / 자료를 훑어보기. |
| `get over` / `get through` | 충격 이후 회복하기와, 힘든 기간 자체를 견뎌내기의 차이. |
| `on paper` / `in practice` | 조건·계획만 놓고 볼 때와 실제 운영해 볼 때. |
| `fob someone off` / `palm something off on someone` | 사람을 핑계로 돌려보내기와, 달갑지 않은 물건 등을 떠넘기기. |

## 말투까지 함께 기억하기

- `Get a grip.`, `Back off.`, `Lay off her.`는 직접 상대에게 말하면 강하게 들린다. 친절한 조언이나 정중한 요청의 기본 표현으로 쓰지 않는다.
- `With all due respect`는 존중을 표시하는 형식이지만 반대가 이어지는 표현이다. 단순한 존댓말 장식처럼 넣기보다, 실제로 반대 의견을 밝힐 때 쓰인다.
- `Tell me about it`은 이 자료의 예문에서는 “자세히 설명해 줘”가 아니라 “내 말이!”라는 맞장구다. 문맥에 따라 문자 그대로의 요청도 가능하다.
- `Take the mickey`는 친근한 놀림도, 불쾌한 조롱도 될 수 있다. 관계와 말투를 함께 본다.
- `No worries`, `give me a shout`, `can't be bothered` 같은 편한 말은 공식 문서보다 대화에 더 잘 맞는다.
- 관용구를 한 문장에 여러 개 넣을 필요는 없다. 정확히 맞는 표현 하나를 자연스럽게 쓰는 쪽으로 연습한다.
