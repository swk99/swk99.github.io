# Phrase Garden — Flutter iPhone edition

Native Flutter learning screens with the same 1,000 expressions as the web edition. Flashcards, reverse cards, 10-question quizzes, listening quizzes, search, topics, favourites, and 1/3/7-day spaced review. All study content is bundled offline. `flutter_tts` uses device speech (UK/US, normal/slow); Cambridge opens its official website and requires internet. Cambridge recordings are not bundled.

## Run on a Mac

Install Flutter, Xcode and CocoaPods as described at https://docs.flutter.dev/platform-integration/ios/setup . From this folder:

```sh
flutter create --platforms=ios --org io.github.swk99 --project-name phrase_garden --no-pub .
rm -f test/widget_test.dart
flutter pub get
flutter analyze --no-fatal-infos
flutter test test
open -a Simulator
flutter devices
flutter run -d <simulator-id>
flutter test integration_test/app_test.dart -d <simulator-id>
```

The iOS host is generated by Flutter rather than hand-written. CI pins Flutter commit `abaf9c523780a608bd46686fd5e53740a07077f8` and packages the generated host plus dependency lockfile in the source artifact. The repository's Dart code and pubspec are retained during generation.

## Install on a physical iPhone

Open `ios/Runner.xcworkspace` in Xcode after generating the host, select your Apple development team under Signing & Capabilities, and use a unique bundle identifier such as `io.github.swk99.phraseGarden`. Connect the iPhone, enable Developer Mode, and run. This needs your Apple account and signing setup. The simulator ZIP cannot be installed on an iPhone. TestFlight requires Apple Developer Program/App Store Connect setup and a signed release; no TestFlight upload is configured here.

## Validation

The `Phrase Garden Flutter iOS` Actions workflow runs static analysis, dataset/review/persistence tests, 320/390-point widget tests, a simulator build, and a native integration test. Only a green completed run establishes these checks passed. Integration tests check actual iOS preferences and the speech plugin bridge; they do not establish audible quality. Physical-device audio, silent-mode behaviour, Bluetooth, VoiceOver and real-device signing need separate device checks.

## Data and privacy

Progress stays in this app's preferences. It is separate from browser localStorage and is not automatically migrated or synchronised. Uninstalling may erase progress. There are no analytics, accounts, server API keys or microphone permissions. External Cambridge navigation sends the selected expression as a normal dictionary query. The app does not record voice.
